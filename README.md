# DS 3001 Semester Project

Fork this repository once for your team and use the fork as the single record of your semester project.

## Project information

- **Project title:** Assessing the Relationship Between Diet and Mental Health in High Schoolers
- **Team members:** Nathan Park, Amelia Chen, Lawson Pham, Amran Belete
- **Repository URL:** https://github.com/lawsonpham/project_template

## Repository structure

```text
.
├── README.md
├── notebook.ipynb
├── final_report.docx
└── data/
    └── README.md
```

- `notebook.ipynb` is the primary notebook. It runs from beginning to end
  and reproduce the results reported in `final_report.docx`.
- `final_report.docx` is the required report template. Complete it without
  changing the filename.
- `data/` contains the data needed to reproduce the analysis or instructions
  for obtaining data that cannot be included in the repository.

## Getting started

1. Fork this repository and clone your team's fork.
2. Replace the project-information placeholders above and in `notebook.ipynb`.
3. Add your data or complete access instructions in `data/README.md`.
4. Develop the complete analysis in `notebook.ipynb` using regular,
   descriptive Git commits.
5. Complete `final_report.docx` from the included template and keep it in the
   repository.

## Before submission

- Restart the notebook kernel and run every cell from beginning to end.
- Confirm that the report links to the repository, `notebook.ipynb`, and the
  data or stable data-access instructions.
- Confirm that all required project files are committed and pushed.
